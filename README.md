# ⚙️ PowerShell Admin Scripts

A collection of **PowerShell** scripts for common IT support and admin tasks, with a focus on **user onboarding and offboarding** in Active Directory. Built and tested in my home lab.

> 🚧 **Status:** In progress.

## 📜 Planned Scripts
| Script | Purpose | Status |
|---|---|---|
| `New-LabUser.ps1` | Create a new AD user with standard settings and groups | ⏳ Planned |
| `Disable-LabUser.ps1` | Offboard a user: disable account, remove groups, log changes | ⏳ Planned |
| `Reset-UserPassword.ps1` | Reset a password and force change at next login | ⏳ Planned |
| `Get-InactiveAccounts.ps1` | Report accounts that haven't logged in recently | ⏳ Planned |
